# ShoraX Tap Cleaner – Website

Single-page product website for ShoraX Tap Cleaner.

## Structure

```
index.html            Page content
css/styles.css        All styles
js/main.js            Discover toggle and flip-card video behaviour
assets/images/        logo.jpg, bottle.png
assets/videos/        shake-well.mp4, spray.mp4, wait.mp4, brush.mp4, rinse.mp4
```

## Publish on GitHub Pages

1. Create a new public repository on GitHub (for example `shorax-website`).
2. Upload the contents of this folder to the repository root, keeping the folders as they are.
3. Go to **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. The site will be live at `https://<your-username>.github.io/<repository-name>/` after a minute or two.
